本文同步自微信公众号“小明同学的笔记”。原文：3个DSH必备插件：让AI Agent从毛坯房变生产力工具

大家好，我是小明同学。

好几个同事装完 DeepSeek Harness (DSH) 都来找我吐槽，说这东西不就是个换皮的网页版对话框吗，跟直接去官网聊没什么区别。其实，DSH 的核心精髓全在它的插件生态里，如果你没装插件，那确实等于住在毛坯房。

截至 2026 年 11 月，DeepSeek 价格方案调整后，成本监控变得非常重要。直接说结论，我天天用 DSH 写代码，踩完一堆坑后只留下了 3 个插件，装上确实能省不少时间。

01 余额实时监控：DeepSeek-Balance-Whale-Widget

跑 Agent 最怕什么？怕它在后台疯狂调用工具刷 Token，等月底收到账单心都在滴血。它堪称防“破产”神器。

它会在界面右下角悬浮一个小鲸鱼挂件，实时显示账户余额。最关键的是，它支持多平台账单监控，不管你用 OpenAI、Kimi 还是硅基流动，都能一键配置查余额。

提示：安装完成后记得在设置里填好 API Key，数据全在本地，不用担心泄露。

02 侧边栏工作台：dsh-better-sidebar

原来的 DSH 界面太素了，写代码时需要来回切换终端、编辑器和浏览器，思路极易被打断。这个插件直接把侧边栏变成了一个 All-in-One 的工作台。

它能直接在侧边栏集成文件渲染编辑器、原生终端和 Git 状态栏。支持左侧开着终端跑脚本，右侧直接在插件内查看文件变更，效率提升不少。

注意：该插件运行要求 DSH 版本在 0.2.2-rc.1 及以上，如果你一直没更新，记得先去官网升个级。

03 系统级交互：dsh-windows-mcp

这是这三个插件里最“硬核”的一个。通过 MCP 协议，它赋予了 AI 操作你 Windows 系统的权限。简单来说，AI 不再是只会“嘴炮”，它能直接控制鼠标和键盘。

你可以让它帮你点开微信、打开报表文件。初次配置时，建议在插件面板里把 Computer Use（电脑使用权）权限单独开启，出于安全考虑，默认是关闭的。

写在最后

DSH 的积木式架构给了我们极大的发挥空间。对于刚入门的开发者，建议先装好监控插件，看懂自己的 Token 消耗曲线，再去尝试这类系统级交互插件。

这三个插件在官方插件市场或 GitHub 仓库均可获取。大家手头还有啥每天写代码必开的插件？评论区顺手甩个名字，我回头拉进项目里测测。
